WELCOME TO THE OFFICE

Every Codex run from Claude Code is a worker at a desk. Live ones type away, with what they are doing right now above their monitor. Finished ones turn around: ✓ done, ! failed, ⏸ paused, z interrupted.

Click a worker to read their whole conversation as it happens: messages, reasoning, every command and its output, web searches, file changes. Then pause them, or send them more instructions, images and @ file references.

A worker's role follows the Codex tool it runs, unless Claude names one with a Role: Product Manager line in the task, or you pick one from the role menu in its header.

Keys: [ ] previous / next worker · / search · Esc close · ⌘+Enter send
